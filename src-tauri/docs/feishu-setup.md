# 飞书机器人配置指南

## 概述

本指南将帮助你在飞书开放平台创建企业自建应用，并配置 OpenClaw 飞书机器人。

---

## 第一步：创建飞书应用

### 1.1 访问飞书开放平台

打开浏览器，访问：[https://open.feishu.cn/app](https://open.feishu.cn/app)

使用你的飞书账号登录。

### 1.2 创建企业自建应用

1. 点击右上角 **"创建企业自建应用"** 按钮
2. 填写应用信息：
   - **应用名称**：OpenClaw Bot（或自定义名称）
   - **应用描述**：AI 助手机器人
   - **应用图标**：上传一个图标（可选）
3. 点击 **"创建"** 完成应用创建

---

## 第二步：获取应用凭证

### 2.1 获取 App ID 和 App Secret

1. 进入应用详情页
2. 在左侧菜单找到 **"凭证与基础信息"**
3. 复制以下信息：
   - **App ID**：形如 `cli_a1b2c3d4e5f6g7h8`
   - **App Secret**：点击 **"查看"** 按钮，复制密钥

⚠️ **重要**：App Secret 是敏感信息，请妥善保管，不要泄露。

---

## 第三步：配置应用权限

### 3.1 开启机器人能力

1. 在左侧菜单找到 **"添加应用能力"**
2. 点击 **"机器人"** 卡片，启用机器人功能

### 3.2 配置权限范围

在左侧菜单找到 **"权限管理"**，开启以下权限：

#### 必需权限（消息与群组）

- ✅ `im:message` - 获取与发送单聊、群组消息
- ✅ `im:message:send_as_bot` - 以应用身份发消息
- ✅ `im:chat` - 获取群组信息
- ✅ `im:chat:readonly` - 获取群组信息（只读）

#### 可选权限（增强功能）

- `im:message.group_at_msg` - 接收群聊 @ 消息
- `im:message.p2p_msg` - 接收单聊消息
- `im:resource` - 获取资源文件

### 3.3 申请权限

1. 勾选所需权限后，点击 **"申请权限"**
2. 等待管理员审批（如果你是管理员，可直接通过）

---

## 第四步：配置事件订阅

### 4.1 配置请求地址

1. 在左侧菜单找到 **"事件订阅"**
2. 点击 **"添加事件"**
3. 配置请求地址：
   ```
   http://your-server-ip:3000/webhook/feishu
   ```
   或使用内网穿透工具（如 ngrok）生成的公网地址

### 4.2 订阅事件

在 **"事件列表"** 中，订阅以下事件：

#### 消息事件

- ✅ `im.message.receive_v1` - 接收消息
- ✅ `im.message.message_read_v1` - 消息已读（可选）

#### 群组事件（可选）

- `im.chat.member.bot.added_v1` - 机器人被添加到群组
- `im.chat.member.bot.deleted_v1` - 机器人被移出群组

### 4.3 保存配置

点击 **"保存"** 按钮，完成事件订阅配置。

---

## 第五步：获取 Chat ID

### 方法一：通过群聊设置获取（推荐）

1. 打开飞书客户端，进入目标群聊
2. 点击右上角 **"..."** → **"设置"**
3. 在群设置页面，找到 **"群 ID"** 或 **"Chat ID"**
4. 复制该 ID（形如 `oc_a1b2c3d4e5f6g7h8`）

### 方法二：通过 API 获取

使用飞书 API 获取群列表：

```bash
curl -X GET \
  'https://open.feishu.cn/open-apis/im/v1/chats' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```

从返回结果中找到目标群聊的 `chat_id`。

---

## 第六步：在 OpenClaw Manager 中配置

### 6.1 填写配置信息

在 OpenClaw Manager 的 **"消息渠道"** 页面，选择 **"飞书"**，填写以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| **App ID** | 应用 ID | `cli_a1b2c3d4e5f6g7h8` |
| **App Secret** | 应用密钥 | `xxxxxxxxxxxxxx` |
| **Chat ID** | 群聊 ID | `oc_a1b2c3d4e5f6g7h8` |

### 6.2 测试连接

1. 点击 **"测试连接"** 按钮
2. 如果配置正确，会在飞书群聊中收到测试消息
3. 如果失败，请检查：
   - App ID 和 App Secret 是否正确
   - Chat ID 是否正确
   - 机器人是否已添加到目标群聊
   - 权限是否已审批通过

### 6.3 保存配置

测试成功后，点击 **"保存配置"** 按钮。

---

## 第七步：将机器人添加到群聊

### 7.1 添加机器人

1. 打开飞书客户端，进入目标群聊
2. 点击右上角 **"..."** → **"设置"**
3. 找到 **"群机器人"** 或 **"添加机器人"**
4. 搜索你创建的应用名称（如 "OpenClaw Bot"）
5. 点击 **"添加"**

### 7.2 验证机器人

在群聊中发送消息 `@OpenClaw Bot 你好`，如果机器人回复，说明配置成功。

## 常见问题

### Q1: 机器人无法接收消息

**可能原因**：
- 事件订阅配置错误
- 请求地址不可访问
- 权限未审批通过

**解决方法**：
1. 检查事件订阅的请求地址是否正确
2. 确保 OpenClaw 服务正在运行（端口 3000）
3. 检查权限管理页面，确认所有权限已通过

### Q2: 提示 "App ID 或 App Secret 错误"

**可能原因**：
- 复制时包含了多余的空格
- App Secret 已过期或被重置

**解决方法**：
1. 重新复制 App ID 和 App Secret，注意去除空格
2. 如果 App Secret 已重置，需要使用新的密钥

### Q3: 无法获取 Chat ID

**可能原因**：
- 群聊设置中未显示 Chat ID
- 使用的是个人聊天而非群聊

**解决方法**：
1. 确保使用的是群聊（不是单聊）
2. 使用方法二通过 API 获取 Chat ID
3. 联系飞书管理员确认群聊权限

### Q4: 机器人回复延迟很高

**可能原因**：
- 网络延迟
- OpenClaw 服务负载过高
- AI 模型响应慢

**解决方法**：
1. 检查网络连接
2. 优化 AI 配置，使用更快的模型
3. 增加服务器资源

### Q5: 机器人被移出群聊后无法重新添加

**可能原因**：
- 应用被禁用
- 权限被撤销

**解决方法**：
1. 检查应用状态，确保应用已启用
2. 重新申请权限
3. 联系飞书管理员确认应用状态

## 进阶配置

### 自定义机器人回复格式

在 OpenClaw 配置文件中，可以自定义机器人的回复格式：

```json
{
  "channels": {
    "feishu": {
      "reply_format": "markdown",
      "enable_rich_text": true,
      "enable_card_message": true
    }
  }
}
```

### 配置多个群聊

如果需要在多个群聊中使用机器人，可以配置多个 Chat ID：

```json
{
  "channels": {
    "feishu": {
      "chat_ids": [
        "oc_a1b2c3d4e5f6g7h8",
        "oc_x1y2z3a4b5c6d7e8"
      ]
    }
  }
}
```
